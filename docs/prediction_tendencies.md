# 予測結果の傾向（成功率が高くなる条件・低くなる条件）

## 検証方法

ノード数・経過時間・周波数・投入時刻・曜日・
メモリ上限をランダムに組み合わせた**300パターン**の条件を生成し、
特定の条件を変えたときに同じ方向へ変化する割合を集計した。

方向が一致した割合が**85%以上**の項目のみを「確認できた傾向」として
記載し、それ未満の項目は「明確な傾向は見られなかった」として扱う。
いずれも学習データ上の統計的な傾向であり、因果関係を示すものではない。

## 確認できた傾向

| 比較 | 方向が一致した割合 | 平均差 |
|---|---|---|
| ノード数1 vs ノード数65536 | 99.0%（少ない方が高い） | -7.8pt |
| 経過時間200時間 vs 24時間 | 93.3%（長い方が低い） | -4.1pt |
| メモリ上限64GiB指定 vs 指定なし | 94.7%（指定する方が高い） | +3.3pt |
| メモリ上限16GiB指定 vs 指定なし | 94.0%（指定する方が高い） | +3.1pt |
| 経過時間150時間 vs 24時間 | 87.3%（長い方が低い） | -2.4pt |

- **ノード数**: 極端に少ない（1ノード程度）方が、極端に多い（数万ノード）
  よりも成功率が高い傾向は、ほぼ全ての条件で一貫していた。ただし中間的な
  規模（数百〜数千ノード）同士の細かい比較では、条件によって順序が
  入れ替わり、一貫した傾向は見られなかった。
- **経過時間上限**: 150〜200時間のような極端に長い設定にすると、24時間
  程度の一般的な設定より成功率が下がる傾向が確認できた。ただし数時間〜
  数十時間の範囲内での細かい比較（例: 3時間 vs 48時間）は条件によって
  方向がまちまちで、一貫した傾向は見られなかった。
- **メモリ上限**: 16GiB以上のようにある程度まとまった値を明示的に指定
  すると、指定しない場合より成功率が高くなる傾向が確認できた。

## 明確な傾向が見られなかった項目

以下は、条件によって方向が逆転し、一般的な傾向として結論づけられな
かった項目である。無理に法則を当てはめず、そのまま記録する。

| 項目 | 検証結果 |
|---|---|
| 投入時刻（深夜0時 vs 正午） | 58.3%が深夜の方が高いという結果で、ほぼ五分五分。平均差もほぼゼロ |
| 投入曜日 | 同一条件内で曜日だけを変えた場合の変動幅は平均1.6ポイントと小さく、最も高い/低い曜日も条件によって入れ替わる |
| 要求周波数（2000MHzが最低か） | 81.7%の条件で最低だったが、約2割の条件では別の値が最低になり、閾値（85%）に届かなかった |
| メモリ上限をごく小さく（1GiB）指定 | 78.3%で「指定なし」より高いという結果で、16GiB以上の場合ほど一貫していない |

これらの項目については、「この条件だと成功率が上がる/下がる」と一概には
言えず、実際に本アプリで具体的な数値を入力して確認するのが最も確実である。

## モデルの挙動についての解釈

ニューラルネットワークは特徴量同士の**組み合わせ（相互作用）**を学習して
いるため、多くの特徴量は「これを上げると必ずこうなる」という単純な
一方向の効果を持たない。今回の検証で明確な傾向が確認できたのは、
「極端に大きい/小さい」「極端に長い」といった**外れ値に近い条件**が
中心であり、通常の範囲内での微妙な違いは、他の条件との組み合わせ次第で
結果が変わる。
